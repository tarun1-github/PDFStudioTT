# Changelog

## [PDFStudio-v0.12.0-beta] - 2026-11-26
- Added Team Document Governance, Version Control (`1.0`, `1.1`, `2.0`), SHA-256 duplicate detection, and immutable published revisions.
- Added 8-state Approval Workflow (`DRAFT`, `SUBMITTED`, `UNDER_REVIEW`, `CHANGES_REQUESTED`, `APPROVED`, `PUBLISHED`, `REJECTED`, `ARCHIVED`) with anti-self-approval enforcement.
- Enhanced Shared Knowledge Library with search, category/technology/status/version filters, version comparison, archival, and role-scoped analytics.
- Consolidated repository documentation under `docs/`.

## [PDFStudio-v0.11.0-beta] - 2026-11-26
- Added 10-stage Professional Learning Book Publisher, 4 cover templates, clickable TOC links, nested bookmarks, chapter dividers, Roman numerals, and 4 PDF compression modes.

## [PDFStudio-v0.10.0-beta] - 2026-11-26
- Added local OCR-based Smart Document Sequencing in PDF Compiler and Learning Book Creator.

## [PDFStudio-v0.9.0-beta] - 2026-11-26
- Initial controlled test deployment on Windows 11 + MSSQL (`CPDB.pdfstudio`).
