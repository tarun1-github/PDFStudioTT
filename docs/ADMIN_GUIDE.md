# Admin Guide

- **User & Role Management**: Manage team accounts and roles (`Engineer`, `Team Lead`, `Admin`) in **User Management** or `/api/admin/users`.
- **Categories**: Add/manage Knowledge Library categories via `POST /api/governance/categories` or **Shared Library -> Analytics & Categories**.
- **Audit Logs**: Review all security, publishing, and governance transitions in `pdfstudio.audit_logs` (`/api/admin/audit-logs`).
- **Settings**: Configure runtime settings via `/api/admin/settings` and `.env`.
